# Cloud Computing Instructor Portfolio

## 📚 Hands-On Instructor Labs

### 1️⃣ Deploying a Web Server on AWS EC2
**Description:**  
Learn how to launch and secure a virtual server on AWS using EC2 and security groups.

**Skills Covered:**  
- Virtual machines  
- SSH access  
- Linux basics  
- Cloud security  

---

### 2️⃣ Identity and Access Management (IAM) Basics
**Description:**  
Create users, groups, and permissions following the principle of least privilege.

**Skills Covered:**  
- IAM users & roles  
- Access control  
- Cloud security best practices  

---

### 3️⃣ Cloud Networking Fundamentals
**Description:**  
Design a basic cloud network using VPCs and subnets.

**Skills Covered:**  
- VPC & subnets  
- Routing tables  
- Security groups  

---

### 4️⃣ Hosting a Static Website in the Cloud
**Description:**  
Host a simple static website using cloud storage services.

**Skills Covered:**  
- Cloud storage  
- Serverless hosting  
- Public access configuration  

---

### 5️⃣ Cloud Monitoring & Logging (Intro)
**Description:**  
Monitor system performance and understand basic logging.

**Skills Covered:**  
- CloudWatch basics  
- Resource monitoring  
- Alerts and metrics
